Flights help

Support

Practical help for recording, organizing, and protecting your flight history.

Add or correct a flight

  1. Open the Flights tab and tap the plus button.
  2. Enter an airport code, airport name, or city, then tap search for each endpoint. Airport lookup requires a network connection to Apple's Maps service.
  3. Add the date and any optional airline, time, aircraft, seat, or note details, then save.
  4. To make a correction, open the flight and tap Edit. Swipe a flight in the list to delete it.

Distances are point-to-point estimates based on the airport coordinates returned by Apple Maps; they may differ from the route actually flown.

Trips, maps, cards, and widgets

  • Create a trip from the Trips tab, choose its dates and color, and assign flights. Open the trip and use Edit to reorder its itinerary.
  • If a map or airport result looks wrong, edit the flight and search again with a more specific airport name or code.
  • Share cards are generated from the trip or selected year's saved totals. Use the system share sheet to choose a destination.
  • If a widget is not current, open Flights so it can refresh its on-device aggregate snapshot, then allow the Home Screen widget a moment to reload.

iCloud synchronization

Flight and trip records use SwiftData and are configured to synchronize through Apple's CloudKit service in your Apple/iCloud environment when available. Make sure you are signed into the intended iCloud account and that network access is available. Synchronization timing is managed by Apple and can vary.

Because CloudKit is enabled, records are not necessarily confined to one device. Deleting a synchronized record may propagate to other devices using the same iCloud environment.

Backups, CSV, and local files

Use the Data menu in the Flights tab to export a JSON backup or a CSV file. Save exports somewhere you control. Import Backup accepts the app's supported JSON backup format and adds or updates matching records without intentionally duplicating matching archive identifiers.

Before replacing a device or making extensive edits, create a fresh JSON backup. Exported files are separate copies and are not removed when an in-app record is deleted.
