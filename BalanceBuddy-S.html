BalanceBuddy Support

Practical help for accounts, transactions, budgets, sync, imports, and backups.

Getting started

Add an account

Open Home or Accounts and add an asset or liability account. Then add transactions manually or choose Import CSV.

Build a budget

Open Budget, choose a month, and add category plans. Review income, spending, rollover, and monthly progress as transactions are categorized.

Recurring activity

Use Settings → Recurring Transactions to add schedules, review the recurring calendar, or look for possible recurring charges in transaction history.

Read-only mode

An active BalanceBuddy Pro subscription is required to add or change financial data. Existing data, exports, backups, and deletion controls remain available when a subscription is inactive. Open Settings → Subscription to view plans or restore purchases.

iCloud synchronization

BalanceBuddy stores financial data on the device and in the user's private iCloud database. Use Settings → iCloud to confirm that iCloud access is available. Availability does not mean every recent change has finished syncing.

  • Confirm every device uses the same Apple Account and has iCloud access.
  • Keep BalanceBuddy open briefly after large imports, restores, or deletions.
  • Check the network connection and available iCloud storage if changes are delayed.
  • When restoring a full backup, close BalanceBuddy on other devices until the restore finishes syncing.

CSV import troubleshooting

  • Choose a CSV file from the system picker and verify the date, description, amount, and optional category columns.
  • Positive and negative amounts must match the mapping shown in the preview.
  • Review flagged rows and possible duplicates before completing the import.
  • If the file cannot be read, export it again as a standard UTF-8 CSV and retry.

Exports and full backups

A transaction CSV can include dates, names and descriptions, amounts, types, account and category names, notes, and recurring names. A full JSON backup can include all accounts, categories, transactions, recurring items, budgets, rules, reconciliations, and balance snapshots.

You start each export and choose its destination through Apple's sharing interface. These financial files are not encrypted by BalanceBuddy. Store them carefully. A recipient or non-Apple destination you select may retain and process its copy under its own practices.

Data recovery and reset

If the persistent store cannot load, use the recovery screen to retry. Before restoring or resetting, create a current backup if possible. Restoring replaces current app data. Erase All Data deletes the app's financial records and synchronizes that deletion through iCloud; default categories are recreated.
